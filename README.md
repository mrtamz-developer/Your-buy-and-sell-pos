# Points of Buy & Sell

A mobile-friendly, local-first buy-and-sell inventory and sales application.

## Included in v1
- Dashboard
- Buy / purchase recording
- Sell / sales cart
- Automatic stock IN and stock OUT
- Product catalog
- Inventory valuation
- Customers
- Suppliers
- Sales/purchase/profit reports
- Local browser storage
- Responsive mobile/desktop UI
- PWA manifest

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages.

## Important
This v1 stores data in the browser's localStorage. It is intended as the functional foundation. The next production phase should add authentication, a cloud database, multi-user access, audit logs, backups, barcode scanning, receipts and payment reconciliation.
